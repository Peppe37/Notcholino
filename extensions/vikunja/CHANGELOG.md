# Vikunja changelog

## [0.1.1]

- Connect to Vikunja instances behind Cloudflare Access using a service token. The extension keeps both tokens in Keychain and never forwards credentials on redirects.

## [0.1.0-beta]

- Connect Vikunja Cloud or a self-hosted instance in Settings → Extensions → Vikunja using an API token stored in Keychain.
- Browse project Kanban boards in the notch, move tasks between manual columns, and add tasks to a project.
- Open a board or task in your browser for full editing.
