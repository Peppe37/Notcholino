# Notcholino 🖤

Notcholino is a beautiful, open-source, and non-commercial app for macOS. It supercharges your MacBook's Notch by turning it into a dynamic hub for Live Activities, Notifications, and interactive tools.

## Features (In Development)
- **Settings:** Native macOS "System Settings" style UI built with SwiftUI.
- **Dynamic Notch:** An elegant, fluid `NSWindow` overlay that seamlessly extends the hardware notch.
- **Raycast Integration:** Full support for controlling Notcholino directly from Raycast.

## Building from source
This project uses `xcodegen` to manage the Xcode project file.
1. Install xcodegen: `brew install xcodegen`
2. Run `xcodegen generate` in the root directory.
3. Open `Notcholino.xcodeproj`.
