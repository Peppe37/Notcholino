What is it?

Notcholino is a free, open-source and non-commercial notch app for macOS. It extends the hardware notch with a fluid overlay that expands on hover and shows what matters: now playing, upcoming events, volume and brightness, and more.

Alpha Notcholino is in early development. Expect rough edges and breaking changes between versions.

Features

Dynamic Notch

A native overlay that blends with the hardware notch, with multi-monitor support.

Now Playing

Control Spotify and Music, and see anything macOS reports as playing: YouTube, Netflix, Prime Video in a browser, Amazon Music and more.

Calendar & Reminders

See upcoming events and the reminders due today, and jump to them in Calendar.

System HUD

Volume and brightness feedback shown in the notch.

Native Settings

A System Settings–style preferences window built with SwiftUI.

Control Center & plugins

Add buttons to the notch with plugins, installed from a built-in store.

Raycast

Raycast integration is in the works.

Plugins

The Control Center panel of the notch holds plugin buttons. Open Settings → Control Center to install plugins from the built-in store: they are downloaded from the releases of this repository, at their latest version, after you confirm and a checksum check.

☕ Espresso

Keeps your Mac and its screen awake, indefinitely or for 10 minutes up to 12 hours, or until a time you pick. Try it in the preview above.

Want to write your own? See the plugins folder on GitHub.

Install

Requires macOS 14 or later. Download the latest build from the Releases page, open the DMG and drag Notcholino to Applications. Then follow the first launch guide below: macOS will block the app the first time.

Prefer building it yourself? Install xcodegen, run xcodegen generate and open Notcholino.xcodeproj. See the README.

First launch: allowing the app

Notcholino is not notarized by Apple yet (that requires a paid developer account), so macOS shows a warning saying it cannot verify the app. This is expected. Here is how to open it:

  1. Open Notcholino from Applications. A message says it could not be opened. Click Done (do not click “Move to Trash”).
  2. Open System Settings → Privacy & Security.
  3. Scroll down to the Security section. You will see “Notcholino.app was blocked”. Click Open Anyway.
  4. Confirm with your password or Touch ID, then click Open. You only need to do this once.

Prefer the Terminal? This removes the quarantine flag and does the same thing:

xattr -dr com.apple.quarantine /Applications/Notcholino.app

Volume and brightness: to show them only in the notch, allow Notcholino in System Settings → Privacy & Security → Accessibility. It is optional: without it, macOS shows its own HUD too.

Why trust it? Notcholino is fully open source: you can read every line of code in the repository, or build the app yourself with Xcode and skip this warning altogether. The release is built automatically by GitHub Actions from the tagged source.

Questions

macOS says it can't verify the app
That is normal for the alpha: follow the first launch guide. It takes four clicks, once.
It asks for permissions again after an update
macOS ties permissions to the app's signature, and updates are signed with a different one-off signature unless the maintainer has set up the fixed certificate. It should stop once releases use it.
The macOS volume HUD still shows
Allow Notcholino in System Settings → Privacy & Security → Accessibility, or click Authorize in Settings → Sound. If it looks switched on there but the HUD still shows, it is a leftover entry from a previous version: click Authorize in Notcholino and it clears it and asks again.
Spotify Like doesn't work
Click Connect next to the controls or in Settings → Now Playing and log in to Spotify. If it says your account is not allowed, open an issue to be added.
YouTube or Netflix doesn't show up
Notcholino shows what macOS lists as playing in Control Center. If the site or app isn't there, it doesn't report to the system. Check that Settings → Now Playing → Detect any app is on.
What does it do with my data?
Nothing leaves your Mac: no analytics, no telemetry, no accounts. It only contacts Spotify (if you connect it, and for cover art) and GitHub (plugins and the latest release). The Spotify token stays in your Keychain.
Is it really free?
Yes. It is open source and free to use, modify and fork under the PolyForm Noncommercial license, which does not allow commercial use or selling it.
