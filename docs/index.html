What is it?

Notcholino is a free, open-source and non-commercial notch app for macOS. It extends the hardware notch with a fluid overlay that expands on hover and shows what matters: now playing, upcoming events, volume and brightness, and more.

Alpha Notcholino is in early development. Expect rough edges and breaking changes between versions.

Features

Dynamic Notch

A native overlay that blends with the hardware notch, with multi-monitor support.

Now Playing

Control music players right from the notch.

Calendar

See upcoming events and jump to them in Calendar.

System HUD

Volume and brightness feedback shown in the notch.

Native Settings

A System Settings–style preferences window built with SwiftUI.

Plugins & Raycast

Plugin architecture and Raycast integration are in the works.

Install

Requires macOS 14 or later. Download the latest build from the Releases page. Since the app is not notarized yet, on first launch right-click it and choose Open.

Prefer building it yourself? Install xcodegen, run xcodegen generate and open Notcholino.xcodeproj. See the README.
