# Changelog

## [0.1.0-alpha] - 2026-10-14

### Added
- First release of Dusty, a clean mode: for 5 to 60 seconds the screen goes black and the keyboard, trackpad and mouse are ignored, so you can wipe them without pressing anything.
- ⌘⇧C ends it at once.
- It needs the Accessibility permission. Without it the screen is not blackened, so you are never left wondering why nothing responds.
