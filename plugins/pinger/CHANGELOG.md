# Changelog

## [0.1.0-alpha] - 2026-10-15

### Added
- First release of Pinger: the latency to a public server (1.1.1.1, 8.8.8.8 or apple.com) as the button, green to red, or OFF when nothing answers. The options show a graph of the last minutes, the average, the packets lost and whether a VPN is on. It opens one small TCP connection every five seconds and closes it at once.
