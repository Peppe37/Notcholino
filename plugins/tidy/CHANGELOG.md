# Changelog

## [0.1.1-alpha] - 2026-10-15

### Changed
- The icons come back when Notcholino quits or the plugin is removed, and after a crash at the next launch, if it was Tidy that hid them: the Desktop is left as if Notcholino had never run.

## [0.1.0-alpha] - 2026-10-15

### Added
- First release of Tidy: a switch that hides the icons on your Desktop (for sharing or recording the screen) and shows them again. It uses Finder's own setting, so the files stay where they are; Finder restarts for the change to apply.
